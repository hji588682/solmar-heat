烈日港湾 · Solmar Heat — a 2D top-down open-world crime game set in the sun-soaked seaside city of Solmar. Milo “Ace” Ferran, a getaway driver in debt to club owner Madame Sol, works it off over five story missions: drive fares, steal a red convertible, lose a 2-star heat, survive a park gunfight, and make a final 3-star run to the pier. Walk and drive, steal cars, dodge a 0–3 star wanted system with pursuing police cars, fight gunmen, and wash your heat at Ray's Spray Shop. Pure JavaScript + Canvas, no libraries, no network — play it offline in a desktop browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
